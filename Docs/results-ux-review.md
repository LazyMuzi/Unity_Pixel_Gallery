# 결과 UI 시안 — 2026-10-02

현재 결과 화면은 작품 미리보기, 열 명의 긴 감상 목록, 정산·성장·부탁 정보가 한 화면에서 경쟁한다. 작품을 보고 감상 하나를 기억한 뒤 판매/보유를 선택하기 쉽도록 네 가지 가로형 시안을 만들었다. 게임 구현은 변경하지 않았다.

## 공식 자료 참고

- [New Pokémon Snap](https://newpokemonsnap.pokemon.com/en-us/create-photodex/): 작품을 평가받고 보관하는 흐름. 작품이 중심인 결과 구성을 제안하는 출발점으로 사용했다. 이 게임의 점수표·등급을 추가하지 않는다.
- [Passpartout 2](https://store.steampowered.com/app/1571100/Passpartout_2_The_Lost_Artist/): 그림, 개성 있는 비평가, 판매의 연결. 익명의 가격만 보여주지 않고 구매 제안자를 연결한다.
- [Drawful](https://www.jackboxgames.com/games/drawful): 그림을 공개하고 다른 사람의 해석·선택으로 재미를 만드는 흐름. 관람객 반응을 둘러보는 카드형의 참고로 사용했다.

공식 소개와 공개 자료의 흐름에서 추론해 재구성한 시안이다. 실제 게임을 실행하거나 해당 게임의 결과 화면과 픽셀 단위로 비교하지 않았다.

## 네 방향

1. 작품과 한마디 — 추천. 큰 작품, 대표 감상 두 개, 전체 감상 펼침, 구매 제안, 두 선택, 정산 후 성장. 기존 진행 단계를 늘리지 않는다.
2. 관람객 카드 — 열 명의 반응을 카드로 선택하고 감상을 한 개씩 읽는다. 인물 탐색이 재미 있지만 정보량이 늘어난다.
3. 미술관의 여운 — 어두운 미술관에 작품을 크게 유지하고 작은 정산 패널을 둔다. 게임 구현 시 기존 3D 미술관 배경과 연결할 수 있다.
4. 감상→정산 — 첫 화면은 작품·감상, 다음은 판매·보유. 정보량을 가장 분명하게 나누지만 탭이 하나 늘어난다.

## 샘플과 기존 규칙

- 작품 ‘낮의 정원’과 숫자는 시안용 샘플이다. 3일차, 좋아요 6명(열성팬 2명 포함), 작품 가치 120코인, 구매 제안 156코인, 부탁 보상 60코인 상황이다.
- 판매는 확인 단계를 유지하며 판매 156 + 부탁 60 = 총 216코인을 구분한다. 보유는 작품을 컬렉션에 남기고 부탁 60코인만 받는다.
- 이번 정산으로 세 번째 전시를 마치는 상황이다. 판매·보유 모두 미술관이 확장되며 다음 전시부터 작품 가치 +20%를 적용한다. 현재 가격을 미리 올리거나 보유도 판매액을 받는 것처럼 표시하지 않는다.
- 확률·신뢰도·기술 특징 수치를 추가하지 않는다.

## 산출물

`results-ux-mockups.html` — 외부 의존성 없는 단일 HTML. 전체 감상, 관람객 선택, 판매 확인, 보유 결과, 단계 전환을 눌러 비교한다. 실제 저장이나 판매를 실행하지 않는다.

## 결과 UI 적용 · 2026-10-02

- 사용자 선택: 1번 작품·대표 감상·정산 배치 + 3번 어두운 미술관 색감.
- 560×560 작품과 금빛 액자, 대표 감상 2개, 전체 감상 펼치기, 구매 제안 및 판매/보유 버튼으로 정리.
- 대표 감상은 단골 방문객과 구매 제안자의 실제 저장된 반응을 표시한다. 동일 인물이면 다른 방문객을 선택한다.
- 부탁 보상과 성장 안내를 별도로 표시하며, 판매 확인 및 완료 안내에는 이번 정산의 부탁 보상을 합산한다. 소장 작품 재판매에는 다시 합산하지 않는다.
- PlayMode 11개 통과. 전체 감상 열기/닫기, 저장된 감상과 가격, 정산·성장·그리기 흐름 검증. 카메라 이동 검증은 고정 시간 대신 완료 상태와 캔버스 갱신을 기다리도록 수정.
- 최종 글자 자동 축소 변경 후 컴파일 오류/경고 없음, 에디터 화면 확인. 실기 검증은 실행하지 않았다.
- 화면: `Docs/results-ui-preview.png`. 실제 저장 파일을 변경하지 않는 메모리 세션에서 촬영했다.
