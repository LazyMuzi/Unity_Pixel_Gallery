# 그리기 화면 UX 검토 — 2026-10-01

## 참고와 판단

- [Passpartout 2 개발자의 그림 도구 소개](https://store.steampowered.com/news/posts/?appids=582550&enddate=1644336009&feed=steam_community_announcements): 쉽고 즐겁게 그림을 그리도록 도구 선택과 크기·색 변경을 중심으로 설계했다는 설명을 참고했다. 실제 게임을 플레이한 비교가 아니라 공개 개발자 설명에 대한 검토다.
- [Chicory 공식 소개](https://chicorygame.com/): 그림 그리기를 주요 상호작용으로 삼는 사례로 확인했다. 이 게임의 세부 UI 배치를 복제하지 않았다.
- ui-ux-pro-max의 터치 영역·대비·단계별 정보 노출 지침을 적용했다. 자동 추천의 Y2K 스타일은 기존 어두운 3D 미술관과 맞지 않아 채택하지 않았다.
- 이 프로젝트에 대한 판단: 제목/코인/컬렉션/채움 수치와 도구가 함께 표시되면 그림보다 관리 작업을 먼저 보게 된다. 그림을 그리는 동안에는 색과 기본 도구를 고르는 행위에 집중하게 하고, 전시 준비와 추가 편집은 별도 단계로 나눈다. 이는 참고 자료에서 직접 입증한 사용성 결과가 아니라 현재 화면에 대한 설계 판단이다.

## 반영

- 기본 화면: 색 8개, 연필/지우개/되돌리기, 현재 도구, 작업실로/완성하고 전시하기.
- 추가 도구 메뉴: 스포이드·확대·축소·비우기 및 기존 큰 붓·채우기·대칭·색 페이지. 기존 제스처와 해금 기능은 유지한다.
- 제목 입력은 전시 확인 단계로 이동했다. 그리기 중 재화/컬렉션/상시 채움 수치를 숨긴다. 미달 그림을 전시하려 할 때만 최소 조건을 안내한다.
- DrawingViewport와 DrawingSurface를 동일한 680×680으로 맞추고 별도 UI 배경 테두리를 제거했다. 카메라는 확대된 이미지 대신 고정된 뷰포트 경계에 맞추므로 확대 중 화면 크기 변경에도 3D 캔버스 정렬을 유지한다.

## 확인

- PlayMode 5개 통과, Console 오류/경고 0개.
- 그리기 면과 마스크 크기 동일, 투명한 UI 테두리, 제목의 전시 단계 배치, 3D 캔버스 하단/상단 투영 정렬을 검사했다.
- 가로 기기 시뮬레이터에서 간소화된 화면을 확인했다. 2배 확대 뒤 카메라 재정렬 시 카메라 이동량은 0이었다.
- 실제 기기의 손가락 가림과 도구 메뉴 발견성은 실기 검증 대상이다.

## 재검토 — 2026-10-02 (수정안, 미구현)

사용자 요청: 현재도 복잡하므로 다른 그리기 게임을 참고해 수정 방안을 검토한다. 이번에는 코드와 공개 자료를 분석했으며 게임 구현이나 실기 검증은 진행하지 않았다.

### 확인한 문제

- 왼쪽 되돌리기는 y=0.44, 팔레트는 y=0.415이며 둘 다 x=-630이다. 높이가 각각 90/80이므로 1080 기준 중심 간격 27에 대해 합산 반높이 85, 약 58만큼 겹치는 구성이다. 실제 기기 검증 전의 코드상 확인이다.
- 고정 8색, 색상환, 현재 색 표시가 함께 존재한다. 기본 화면에는 도구/색 조작 13개와 상단 이동/완료 2개가 분산되어 있다.
- 추가 도구는 전체 화면을 덮으며 잠긴 도구를 누르면 상점으로 이동한다. 색 선택은 펼치기→조절→사용 확인으로 그림 흐름을 끊는다.
- 캔버스는 680 정사각형이며 62개의 격자 선과 빈 칸 체크무늬가 기본으로 보인다. 배경·캐릭터·여러 큰 텍스트 버튼과 함께 시각 정보가 많다.

### 추천 수정안

1. 왼쪽 고정 도구막대: 연필/지우개/현재 색/되돌리기/더보기 5개. 현재 도구는 선택 상태로 표시하고 별도 상태 문구는 없앤다. 색상표 8개는 기본 화면에서 제거한다.
2. 현재 색을 누르면 같은 자리에서 색상환을 펼친다. 최근 사용한 색 4개는 이 패널 안에만 둔다. ‘이 색 사용하기’와 ‘닫기’의 중복 버튼을 없애고 선택 후 바깥이나 캔버스 탭으로 닫는다. 조절 중에는 미리보기만 갱신하고 색 저장은 확정/실제 그리기 시점에 처리해 드래그마다 색 슬롯을 소비하지 않는다. 메뉴를 닫는 첫 캔버스 탭은 그림을 찍지 않는다.
3. 더보기는 화면 전체 대신 작은 옆 패널로 열어 큰 붓/채우기/대칭/스포이드와 보기 옵션을 묶는다. 비우기는 구분된 메뉴에 두고 기존 확인과 되돌리기를 유지한다. 잠긴 도구는 잠김을 안내하고 그리기 중 상점으로 전환하지 않는다.
4. 상단은 작은 작업실 복귀와 ‘완료’만 유지한다. 버튼 크기는 실기 터치 영역을 확보하면서 시각적 강조를 낮춘다. 완료 이후 전시 확인에서 제목과 전시 시작을 처리한다.
5. 캔버스는 가용 높이 기준 약 75~80%를 확보하고 기존 카메라 정렬 경로를 사용한다. 기본 격자/체크무늬는 줄여 따뜻한 단색 바탕으로 보이고 격자는 확대/보기 옵션에서 사용한다. 캐릭터와 어두운 3D 작업실은 유지하되 캔버스 주변 배경의 대비를 낮춘다.

우선순위: 버튼 겹침 해소·기본 도구막대 정리 → 팔레트 조작 단축 → 캔버스 확대/격자 정리. 구현 시 Editor에서 입력/저장/카메라 정렬을 검증하며 실제 기기 검증은 사용자 승인 후 진행한다.
