# 그리기 화면 UX 검토 — 2026-10-01

## 참고와 판단

- [Passpartout 2 개발자의 그림 도구 소개](https://store.steampowered.com/news/posts/?appids=582550&enddate=1644336009&feed=steam_community_announcements): 쉽고 즐겁게 그림을 그리도록 도구 선택과 크기·색 변경을 중심으로 설계했다는 설명을 참고했다. 실제 게임을 플레이한 비교가 아니라 공개 개발자 설명에 대한 검토다.
- [Chicory 공식 소개](https://chicorygame.com/): 그림 그리기를 주요 상호작용으로 삼는 사례로 확인했다. 이 게임의 세부 UI 배치를 복제하지 않았다.
- ui-ux-pro-max의 터치 영역·대비·단계별 정보 노출 지침을 적용했다. 자동 추천의 Y2K 스타일은 기존 어두운 3D 미술관과 맞지 않아 채택하지 않았다.
- 이 프로젝트에 대한 판단: 제목/코인/컬렉션/채움 수치와 도구가 함께 표시되면 그림보다 관리 작업을 먼저 보게 된다. 그림을 그리는 동안에는 색과 기본 도구를 고르는 행위에 집중하게 하고, 전시 준비와 추가 편집은 별도 단계로 나눈다. 이는 참고 자료에서 직접 입증한 사용성 결과가 아니라 현재 화면에 대한 설계 판단이다.

## 반영

- 기본 화면: 색 8개, 연필/지우개/되돌리기, 현재 도구, 작업실로/완성하고 전시하기.
- 추가 도구 메뉴: 스포이드·확대·축소·비우기 및 기존 큰 붓·채우기·대칭·색 페이지. 기존 제스처와 해금 기능은 유지한다.
- 제목 입력은 전시 확인 단계로 이동했다. 그리기 중 재화/컬렉션/상시 채움 수치를 숨긴다. 미달 그림을 전시하려 할 때만 최소 조건을 안내한다.
- DrawingViewport와 DrawingSurface를 동일한 680×680으로 맞추고 별도 UI 배경 테두리를 제거했다. 카메라는 확대된 이미지 대신 고정된 뷰포트 경계에 맞추므로 확대 중 화면 크기 변경에도 3D 캔버스 정렬을 유지한다.

## 확인

- PlayMode 5개 통과, Console 오류/경고 0개.
- 그리기 면과 마스크 크기 동일, 투명한 UI 테두리, 제목의 전시 단계 배치, 3D 캔버스 하단/상단 투영 정렬을 검사했다.
- 가로 기기 시뮬레이터에서 간소화된 화면을 확인했다. 2배 확대 뒤 카메라 재정렬 시 카메라 이동량은 0이었다.
- 실제 기기의 손가락 가림과 도구 메뉴 발견성은 실기 검증 대상이다.
