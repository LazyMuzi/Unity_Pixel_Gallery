# 터치·관람 동선 검증 — 2026-10-01

Unity 6000.6.3f1 / URP / Android IL2CPP ARM64. 3D 표현과 기존 UI 배치를 유지했다.

## 수정

- 확대된 그림의 입력 범위를 고정 뷰포트로 제한했다. 화면 밖 영역을 누르거나 드래그해도 칠해지지 않는다.
- 두 손가락 입력을 PointerDown에서도 확인해 확대 시작 시 불필요한 점이 찍히지 않도록 했다. 그리기 화면을 닫을 때 제스처 상태를 초기화한다.
- 작품 앞 관람 위치를 분산하고 이동 중 관람객 사이에 0.6 단위 간격을 확보한다. 기존 이동·작품 관람·이모지·평가 흐름을 유지한다.

## 자동 검증

PlayMode 7/7 통과 (8.726초, job `77d3f17ffe69473d924e01fdda7f2de1`). Console 컴파일 오류/경고 0개.

- 확대 영역 밖 클릭·드래그 거부, 정상 영역 칠하기와 실행 취소.
- Input System의 두 터치 이벤트로 확대하되 그림을 칠하지 않음. 화면을 닫고 다시 열어 한 손가락 입력 가능.
- 관람객 10명, 140초 분량 시뮬레이션에서 최소 간격 >0.45 단위. 다른 작품 관람 >10회, 사용자 작품은 각자 한 번씩 평가.
- 기존 카메라 정렬, 화가 애니메이션, 저장·전시·판매·해금 흐름.

수정 전 별도 180초 시뮬레이션에서는 최소 간격 0.0142 단위가 관측됐다. 시간 조건이 달라 동일 조건의 개선 비율로 비교하지 않는다.

## 실제 손가락 UX 확인 항목

자동 입력 검사는 손가락이 화면을 가리는 정도나 손에 느껴지는 조작감을 검증하지 않는다. 실제 기기에서 다음을 확인한다.

1. 기본 연필로 모서리까지 그린다 → 도구가 그림을 가리지 않고 터치한 셀이 칠해진다.
2. 두 손가락으로 확대·이동한다 → 점이 추가되지 않고 보이는 영역 안에서만 그릴 수 있다.
3. 도구 메뉴에서 도구·색상을 바꾸고 닫는다 → 캔버스로 바로 돌아와 한 손가락으로 그릴 수 있다.
4. 작업실로 나갔다 다시 들어온다 → 확대 제스처 상태가 남지 않고 초안이 보존된다.

## Android 성능 측정

Galaxy S24 Ultra (SM-S928N) 연결 확인. 별도 앱 ID `com.lazymuzi.pixelgallery.devtest`로 개발 빌드를 측정한다. 측정 세션은 메모리만 사용한다.

임시 측정 코드 원본: `device-smoke-probe.cs.txt`. `PIXELGALLERY_DEVICE_PROBE` 정의가 있는 빌드에서만 동작하며 작업실·그리기·전시 각각 준비 1초 후 6초 동안 프레임 간격과 렌더 카운터를 기록한다. 개발 빌드의 짧은 측정이며 저사양·발열·장시간 성능을 대표하지 않는다.

### 측정 결과

Android 빌드·설치·실행 성공. 최종 측정 프로세스 PID 11493의 세 단계와 완료 로그를 확인했다. 평균 약 30fps이며 프레임 간격은 다음과 같다.

| 화면 | 평균 ms | 최대 ms | 평균 삼각형 수 |
|---|---:|---:|---:|
| 작업실 | 33.28769 | 33.32032 | 21,691 |
| 그리기 | 33.28890 | 33.32369 | 18,279 |
| 전시 | 33.28724 | 33.30648 | 180,894 |

각 화면 181프레임, 약 6.025초. 이 값은 GPU 처리 시간이나 최대 처리 가능한 fps가 아니라 실제 프레임 간격이다. Draw Calls 카운터는 0을 반환해 유효한 수치를 얻지 못했다. 60fps나 저사양 기기의 성능은 아직 검증하지 않았다.

빌드 호출 중복으로 재실행된 앞선 프로세스는 측정에서 제외했다. 임시 빌드 콜백을 제거한 후 빌드 종료와 원래 앱 ID 복원을 확인했다. 로그 `android-device-probe.log`에는 재실행 기록도 포함한다.

`Builds/Android/PixelGallery-DeviceCheck.apk`는 저장하지 않는 자동 측정용 개발 APK이다. 배포용 게임 빌드로 사용하지 않는다. 임시 측정 스크립트는 Unity AssetDatabase API로 제거했고, 재현용 텍스트만 문서에 보존했다. 기존 제품 설정과 세이브는 유지한다.
